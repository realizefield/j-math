① 同じ値なのに，見た目が違う？
📌 $\sqrt{12}$ と $2\sqrt{3}$ を比べてみよう
$\sqrt{12} \approx 3.464$
$2\sqrt{3} \approx 2 \times 1.732 = 3.464$
同じ値なのに，見た目がまったく違う！
数学では，ルートの中はできるだけ小さい数にするのが基本のマナー。$\sqrt{12}$ より $2\sqrt{3}$ の方が「簡単な形」！
② $\sqrt{12}$ が $2\sqrt{3}$ になる仕組み
📌 SQ03で学んだこと
$\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ でした。これを逆向きに使います。
📌 重要公式
$$\sqrt{a^2 \times b} = a\sqrt{b}$$ （ただし $a > 0$，$b \geq 0$）
📌 言葉でいうと
ルートの中に「2乗の数」が隠れていたら，その数だけルートの外に出せる！
では，その「隠れた2乗」を見つけるにはどうすればいいでしょうか。
③ 見つけ方は「素因数分解」が確実
📌 素因数分解とは
数を，素数（それ以上分けられない数）だけの積に分けることです。
√の中の数を素因数分解すると，「同じ数が2個ペア」になっている部分が必ず見えてきます。このペアが，外に出せる「隠れた2乗」です。
📌 手順はいつも同じ4ステップ
① √の中の数を，素数で割り続けて素因数分解する（筆算を使う）
② 同じ数が2個ペアになっている部分を探す
③ ペア1組につき，その数を1個だけ√の外に出す
④ ペアになれずに1個だけ余った数は，そのまま√の中に残す
注）素数とは，1と自分自身以外に約数をもたない数のことです。
（例）3 → 約数は1と3　　11 → 約数は1と11　　17 → 約数は1と17
素因数分解では，2・3・5・7・11…という素数で，小さい方から順に割っていきます。
実際にやるときは，2 → 3 → 5 → 7 の順に割ってみると，ほとんどの問題はそれで解けます。この4つの数で割れなくなったら，そこでストップ！
④ 例題①：$\sqrt{12}$ を素因数分解で解く
$\sqrt{12}$ を素因数分解で簡単にする
2 ) 12
2 )  6
     3
①分解
筆算より，$12 = 2 \times 2 \times 3 = 2^2 \times 3$
②ペア
$2^2$（2が2個）が見つかった。$3$ は1個だけ余る
③外に出す
$\sqrt{12} = \sqrt{2^2 \times 3} = \sqrt{2^2} \times \sqrt{3}$
④仕上げ
$\sqrt{2^2} = 2$ なので，$\sqrt{2^2} \times \sqrt{3} = 2\sqrt{3}$
$\sqrt{12} = 2\sqrt{3}$
⑤ 例題②：$\sqrt{18}$ を素因数分解で解く
$\sqrt{18}$ を素因数分解で簡単にする
2 ) 18
3 )  9
     3
①分解
筆算より，$18 = 2 \times 3 \times 3 = 2 \times 3^2$
②ペア
$3^2$（3が2個）が見つかった。$2$ は1個だけ余る
③外に出す
$\sqrt{18} = \sqrt{3^2 \times 2} = \sqrt{3^2} \times \sqrt{2}$
④仕上げ
$\sqrt{3^2} = 3$ なので，$\sqrt{3^2} \times \sqrt{2} = 3\sqrt{2}$
$\sqrt{18} = 3\sqrt{2}$
⑥ 例題③：ペアが2組になる場合（$\sqrt{144}$）
$\sqrt{144}$ を素因数分解で簡単にする
2 ) 144
2 )  72
2 )  36
2 )  18
3 )   9
      3
①分解
筆算より，$144 = 2^4 \times 3^2$
②ペア
$2^4 = 2^2 \times 2^2$ と $3^2$ ── ペアが2組できる。余りはなし
③外に出す
ペアごとに1個ずつ外に出す → $2 \times 2 \times 3 = 12$
$\sqrt{144} = 12$（√がとれて整数になる）
ペアが余りなくすべて外に出せると，ルートが消えて整数になります。これは「$144$ 自体が平方数だった」ということです。
⑦ 数が大きくても迷わない
❗ 「勘」で平方数を探すと，やり直しになることがある
もし $\sqrt{72}$ を，見た感じで小さい平方数 $4$ を使って分けると…
$\sqrt{72} = \sqrt{4 \times 18} = 2\sqrt{18}$ ← まだ $\sqrt{18}$ の中に $9$ が隠れていて，もう一度やり直しになる。
📌 素因数分解なら，1回の筆算で全部見つかる
どんな数も，素数で割り続ければ必ず「これ以上割れない」形にたどり着きます。勘で探す必要がなく，やり直しも起きません。
$\sqrt{72}$ を素因数分解で簡単にする
2 ) 72
2 ) 36
2 ) 18
3 )  9
     3
①分解
筆算より，$72 = 2^3 \times 3^2 = (2^2 \times 2) \times 3^2$
②ペア
$2^2$ と $3^2$ がペア。$2$ が1個だけ余る
③外に出す
ペアの $2^2$ と $3^2$ → $2 \times 3 = 6$ が外に出る
④仕上げ
余った $2$ はそのまま中に残る
$\sqrt{72} = 6\sqrt{2}$
このセクションのまとめ
📌 まとめ
  • $\sqrt{a^2 \times b} = a\sqrt{b}$ ── ルートの中の「2個ペア」は外に出せる
  • ペアを見つける確実な方法は素因数分解（素数で割り続ける筆算）
  • 手順はいつも同じ：①分解 → ②ペアを探す → ③外に出す → ④余りは中に残す
  • ペアが余りなく全部出せると，√がとれて整数になる
  • 数が大きくても，勘で探さず素因数分解すれば必ず解ける

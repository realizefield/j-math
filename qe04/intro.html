因数分解で解く（共通因数）
$x^2 + bx = 0$ の形・$x$ をくくり出す！

① QE03と何がちがう？
📌 たとえば $x^2 - 3x = 0$
QE03 では「たして・かける」で因数分解したけど，
この式には 定数項がない！（$= 0$ の前に数字だけの項がない）
こういうときは $x$ をくくり出す 方法を使う。
② 共通因数でくくり出す
📌 共通因数のくくり出し
$x^2 + bx = x(x + b)$
📌 なぜこうなる？
$x^2$ も $bx$ も，どちらも $x$ を因数として持っている。
だから $x$ を外に出すことができる！
$x^2 - 3x = x(x - 3)$
定数項がない（$x^2 + bx = 0$ の形）を見たら，まず「$x$ でくくれないか？」と考えよう！
③ $x^2 - 3x = 0$ を解こう
📌 ステップ１：$x$ でくくり出す
$x^2 - 3x = 0$
→ 両辺に $x$ の因数がある
→ $x(x - 3) = 0$
$x^2 - 3x = x(x-3) = 0$
📌 ステップ２：ゼロ積の法則を使う
$x(x-3) = 0$ は「$\bigcirc \times \square = 0$」の形！
→ $x = 0$ または $x - 3 = 0$
$x = 0$    または    $x = 3$
$x = 0, 3$
$x^2 - 3x = 0$ を両辺 $x$ で割って $x - 3 = 0$ としてはいけない！$x = 0$ の解が消えてしまう。
④ 係数があるパターン
📌 $2x^2 - 6x = 0$ のとき
$2x^2 - 6x = 0$
→ $x$ だけでなく $2x$ でもくくれる
→ $2x(x - 3) = 0$
→ $2x = 0$ または $x - 3 = 0$
→ $x = 0$ または $x = 3$
💡 くくり出せる数を探すコツ
各項の最大公約数を探す！
例：$2x^2 - 6x$ → 係数は $2$ と $6$，共通因数は $2x$
例：$3x^2 + 9x$ → 係数は $3$ と $9$，共通因数は $3x$
⑤ 例で確認しよう
例１）$x^2 + 5x = 0$ を解く
くくり出す
$x^2 + 5x = x(x + 5) = 0$
ゼロ積
$x = 0$ または $x + 5 = 0$
答え
$x = 0, -5$
$x = 0, -5$
例２）$3x^2 - 12x = 0$ を解く
くくり出す
$3x^2 - 12x = 3x(x - 4) = 0$
ゼロ積
$3x = 0$ または $x - 4 = 0$
答え
$x = 0, 4$
$x = 0, 4$
例３）$x^2 = 7x$ を解く（移項が必要！）
まず移項
$x^2 - 7x = 0$（右辺を $0$ にする）
くくり出す
$x(x - 7) = 0$
答え
$x = 0, 7$
$x = 0, 7$
📌 まとめ
  • 定数項がない（$x^2 + bx = 0$）→ $x$ をくくり出す！
  • $x(x + b) = 0$ の形にしてゼロ積の法則を使う
  • 解は必ず $x = 0$ を含む（忘れがち！）
  • 両辺を $x$ で割るのは NG（$x = 0$ の解が消える）
  • $x^2 = bx$ の形は 先に移項 して $= 0$ にする
  • 係数がある場合は最大公約数でくくり出す（例：$2x^2 - 8x = 2x(x-4)$）

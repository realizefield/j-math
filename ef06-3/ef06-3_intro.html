パターン3のルール
📌 パターン3：χ²＋bχ－c　または　χ²－bχ－c（c＞0）
定数項がマイナス
→ 2数は符号が逆（一方＋，一方－）
→ 数の大きい方がχの係数と同じ符号
🤔 なぜ符号が逆になるの？
1
定数項がマイナス → 2数をかけるとマイナスになる
プラス×マイナス だけがマイナスになるので，2数は必ず符号が逆
2
まずプラスの整数の組の中から，かけて定数項の絶対値になる組を探す
例：定数項が－15 → かけて 15 になる組を探す → (1,15)，(3,5)
3
見つかった組のどちらにマイナスをつけるかは，χの係数で決める
→ 数の大きい方をχの係数と同じ符号にする
4
例：χ²＋2χ－15　→　かけて15：(1,15)，(3,5)
χの係数は ＋2（プラス）→ 大きい方の5を＋にする
→ ＋5と－3　確認：5＋(－3)＝2 ✅　5×(－3)＝－15 ✅
「かけてマイナス → 符号が逆」「たしてプラス → 大きい方がプラス」「たしてマイナス → 大きい方がマイナス」の3つを覚えよう！
例１）χ²＋3χ－4 を因数分解する
確認
c＝－4（－）　→ パターン3：2数は符号が逆
探す
かけて4 の正の整数の組：(1,4)，(2,2)　→ たして＋3 は 1と4
答え
大きい方(4)が＋ → ＋4と－1
(χ＋4)(χ－1)
例２）χ²－3χ－10 を因数分解する
確認
c＝－10（－）　→ パターン3：2数は符号が逆
探す
かけて10 の正の整数の組：(1,10)，(2,5)　→ たして－3 は 2と5
答え
大きい方(5)が－ → －5と＋2
(χ＋2)(χ－5)

パターン2のルール
📌 パターン2：χ²－bχ＋c（b＞0，c＞0）
定数項 c がプラス，χの係数 b がマイナス
→ 2数はどちらもマイナス（負の整数）
→ かけてc，たして－b になる負の整数の組を探す
→ パターン1の2数に両方マイナスをつけるだけ！
🤔 なぜ両方マイナスになるの？
1
かけてプラス → 2数は同符号（両＋か両－）
2
たしてマイナス → 2数の合計がマイナス
同符号でたしてマイナス → 両方マイナスに決定！
3
パターン1と同じ絶対値の組を探して，両方にマイナスをつける
χ²－7χ＋12　→　かけて12，たして－7　→　－3と－4
定数項（プラス）を見てまずパターン1の組を探し，χの係数がマイナスなら両方にマイナスをつけるだけ！
例１）χ²－5χ＋4 を因数分解する
確認
c＝4（＋），b＝－5（－）　→ パターン2：2数とも－
探す
かけて4 の正の組：(1,4)，(2,2)　→ たして5 は 1と4
答え
両方マイナス → －1と－4
(χ－1)(χ－4)
例２）χ²－7χ＋12 を因数分解する
確認
c＝12（＋），b＝－7（－）　→ パターン2：2数とも－
探す
かけて12 の正の組：(1,12)，(2,6)，(3,4)　→ たして7 は 3と4
答え
両方マイナス → －3と－4
(χ－3)(χ－4)
